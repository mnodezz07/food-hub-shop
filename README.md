
# Food Hub

Food Hub is a React-based single-page application for browsing and managing coffee and food products. The application allows users to view available products, search through the product list, view product details, create new products, edit existing products, and delete products.

The project demonstrates the use of React components, state management, React Router, REST APIs, and CRUD operations.

# Features
 1. View a list of coffee/food products
 2. Search and filter products
 3. View detailed product information
 4. Add new products
 5. Edit existing products
 6. Delete products
 7. Navigate between pages using React Router

# Getting Started
Prerequisites - Before running the project, make sure you have the following installed:

1. Node.js
2. npm
3. Git

# Installation

Clone the repository
```bash
git clone <repository-url>
```

```bash
cd food-hub
```

```bash
npm run dev 
```

# Running the JSON Server

The application requires JSON Server to provide the local REST API.
```bash
npm run server
```
